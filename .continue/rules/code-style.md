When generating or editing code:
- Prefer editing an existing nearby file over creating a new one
- Keep functions small and named by intent
- Add a file header in non-trivial files
- Add section headers in non-trivial files
- Comment non-obvious logic, boundaries, and assumptions
- Do not rewrite whole files unless necessary
- Do not introduce vague helpers like doThing, handleStuff, or processData
